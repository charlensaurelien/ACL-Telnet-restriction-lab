This lab demonstrates basic network security using a Cisco router and switch in Packet Tracer. The topology includes two PCs connected through a switch to a router in the 192.168.1.0/24 network.

An extended ACL (ACL 100) is configured on the router to deny Telnet access from PC (192.168.1.2) to the router (192.168.1.1), while allowing all other IP traffic. This shows how ACLs can be used to control specific types of traffic and improve security.

The router is configured with a VTY line password and allows remote access using Telnet. This lab highlights the importance of restricting insecure protocols like Telnet and demonstrates basic access control in a network.

This project is useful for understanding how to protect network devices from unauthorized access while maintaining normal network communication.
